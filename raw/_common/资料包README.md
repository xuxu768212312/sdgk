## 使用原则

1. 先看学生选科，过滤不可报专业。
2. 本科和专科分开建池，不能混用计划和历史数据。
3. 优先比较位次，不直接跨年比较分数。
4. 第 2 次、第 3 次志愿必须使用当次剩余计划或院校专业计划。
5. 每条志愿都要核查招生章程、体检限制、学费、校区、外语语种和单科要求。
6. 最终以山东省教育招生考试院最新发布和高校招生章程为准。
