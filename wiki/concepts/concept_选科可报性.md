# 选科组合可报性

选科组合决定一个学生能报多少专业、能报哪些学校。这是志愿填报的 **第一道筛选**，也是最容易产生幻觉的环节。

## 4 种选考科目要求类型

高校专业对选考科目的要求分 4 种（[[concept_选科要求]]）：

| 类型 | 含义 | 考生是否能报 |
|---|---|---|
| 不提科目要求 | 任何选科组合 | 所有考生均可报 |
| 1 门科目必须选考 | 指定 1 科 | 考生选了这 1 科即可报 |
| 2 门科目均须选考 | 指定 2 科 | 考生必须同时选了这 2 科 |
| 3 门科目均须选考 | 指定 3 科 | 考生必须同时选了这 3 科 |

**关键规则**：指定 2 科或 3 科时，**必须同时选考全部指定科目**，缺一不可。

## 20 种选科组合

山东 3+3 模式从 6 科（物化生政史地）选 3 科，共 **20 种组合**。按专业覆盖率大致排序：

### 第一梯队：物化类（覆盖率最高，约 96-97%）

| 组合 | 可报覆盖率 | 特点 |
|---|---|---|
| 物理+化学+生物 | 约 96.5% | 传统理科，理工医全覆盖 |
| 物理+化学+地理 | 约 96.4% | 工科地学优势 |
| 物理+化学+政治 | 约 96.4% | 加分项：军校公安政审 |

物化组合 2024 起是理工医类专业的硬门槛。教育部 2024 年通用版选科要求中，**绝大多数理工农医类专业要求"物理+化学"**。

### 第二梯队：物化缺失的物理类（覆盖率骤降，约 50-55%）

| 组合 | 可报覆盖率 | 限制 |
|---|---|---|
| 物理+生物+地理 | 约 51% | 理工医大多不能报 |
| 物理+生物+政治 | 约 51% | 同上 |
| 物理+地理+政治 | 约 51% | 同上 |
| 物理+生物+历史 | 约 53% | 同上 |
| 物理+地理+历史 | 约 53% | 同上 |
| 物理+政治+历史 | 约 53% | 同上 |

**重要**：只有物理没有化学，2024 版选科要求下大量理工类专业不可报。这是 2024 年改革后的重大变化。

### 第三梯队：历史类（覆盖率约 34-50%）

| 组合 | 可报覆盖率 | 特点 |
|---|---|---|
| 历史+政治+地理 | 约 49.3% | 传统文科，法学/文学/语言 |
| 历史+政治+生物 | 约 49.8% | 法学优势 |
| 历史+地理+生物 | 约 46% | 文科为主 |
| 历史+生物+化学 | 约 44% | 医学部分可报（中医等） |
| 历史+化学+地理 | 约 44% | 部分化学类 |
| 历史+政治+化学 | 约 49.5% | 法学+部分化学 |
| 历史+化学+生物 | 约 43% | 部分医学（中医、护理） |
| 历史+地理+政治 | 约 49% | 同史政地 |
| 历史+生物+地理 | 约 46% | 文科为主 |

### 第四梯队：纯文科组合（覆盖率最低）

| 组合 | 可报覆盖率 | 限制 |
|---|---|---|
| 政治+地理+生物 | 约 42% | 理工医基本不可报 |
| 政治+生物+地理 | 约 42% | 同上 |
| 地理+生物+化学 | 约 44% | 部分农林可报 |

**注意**：上述覆盖率是估算值，**实际以 `processed/选科要求/` 数据为准**。不同年份、不同版本（2024 vs 2027）有差异。

## 精确查询方法（避免幻觉）

正式判断某个“专业（专业类）+ 学校”能否报考时，必须使用选科索引脚本：

```bash
python scripts/check_subject_eligibility.py --year 2026 --level 本科 --subjects 物理,化学,生物 --school-code <院校代码> --major-code <专业代码> --json
```

正式 96 志愿方案必须使用 `scripts/audit_volunteer_subjects.py` 生成审核报告；任何 `BLOCK` 或 `REVIEW` 都会阻断交付。下面的代码片段只用于探索覆盖率和教学说明，不得替代正式审核闸门。

### 查询某组合能报哪些专业

```python
import json

# 加载 2024 版本科选科要求
data = json.load(open("processed/选科要求/2024版本科.json", encoding='utf-8'))

# 张三选科：物理+化学+生物
my_subjects = {'物理', '化学', '生物'}

def can_apply(rec):
    req_type = rec['subject_requirement_type']
    if req_type == 'none':
        return True
    required = set(rec['subjects_list'].split('|')) if rec['subjects_list'] else set()
    if req_type == 'one':
        return required.issubset(my_subjects)
    if req_type in ('two', 'three'):
        return required.issubset(my_subjects)
    return False

applicable = [r for r in data if can_apply(r)]
print(f"可报专业数: {len(applicable)} / 总数: {len(data)}")
print(f"覆盖率: {len(applicable)/len(data)*100:.1f}%")
```

### 查询某专业能否报

```python
# 查临床医学
clinical = [r for r in data if '临床医学' in r['major_name']]
for r in clinical[:5]:
    can = can_apply(r)
    print(f"{r['school_name']} {r['major_name']}: {'✓可报' if can else '✗不可报'} (要求: {r['subjects_list']})")
```

### 查某学校所有可报专业

```python
# 查山东大学所有专业对张三的可报性
sd = [r for r in data if r['school_name'] == '山东大学']
for r in sd:
    can = can_apply(r)
    print(f"{r['major_code']} {r['major_name'][:30]}: {'✓' if can else '✗'} (要求: {r['subjects_list'] or '不限'})")
```

## 数据来源

| 版本 | 适用届数 | 位置 |
|---|---|---|
| 2024 通用版 | 2025、2026 届 | `processed/选科要求/2024版本科.json` + `2024版专科.json` |
| 2027 通用版 | 2027 届及以后 | `processed/选科要求/2027版本科.json` + `2027版专科.json` |

**2026 届主要使用 2024 版**。最终以《2026 年山东省普通高校招生填报志愿指南》公布的选科要求为准。

## 避免幻觉的关键

1. **不凭印象判断**：不能说"物化生能报所有专业"——**必须查具体数据**
2. **不跨版本混用**：2024 版和 2027 版要求不同，2026 届只用 2024 版
3. **查具体专业代码**：同一专业名称在不同学校要求可能不同（如临床医学 A 校要求物化生，B 校只要求物化）
4. **以官方计划为准**：选科要求是初筛，最终以当年招生计划为准
5. **注意"专业类"包含的具体专业**：大类招生的专业类包含多个具体专业，分流时可能受限

## 选科建议维度

选科决策时需平衡：

| 维度 | 考虑因素 |
|---|---|
| 专业覆盖率 | 物化类最高，历史类较低 |
| 个人成绩 | 选擅长科目，赋分更优（见 [[concept_赋分制]]） |
| 专业意向 | 已明确专业方向，按专业反推选科 |
| 学科难度 | 物理、化学学习难度高，需评估自身能力 |
| 竞争密度 | 热门组合（物化生）竞争激烈，影响赋分位次 |
