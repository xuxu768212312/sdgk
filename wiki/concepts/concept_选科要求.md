# 选科要求

高校专业对等级考科目提出要求，是志愿填报的 **第一道筛选**。山东 3+3 模式下，高校专业可提出 5 种选科要求。

## 5 种要求类型

| 类型 | 含义 | 示例 | 考生选考要求 |
|---|---|---|---|
| **不提科目要求** | 任何组合都可报 | `不提科目要求` | 6 科中任选 3 科 |
| **1 科要求** | 必须选考该科目 | `思想政治(1门科目考生必须选考方可报考)` | 选考中必须含该科 |
| **2 科要求** | 必须同时选考这两科 | `物理,化学(2门科目考生均须选考方可报考)` | 选考中必须同时含这两科 |
| **3 科要求** | 必须同时选考这三科 | `物理,化学,生物(3门科目考生均须选考方可报考)` | 选考中必须同时含这三科 |
| **或类型** | 多科中任选一门 | `物理或化学` | 选考中含其中任一门即可 |

**关键**：
- 2 科或 3 科要求是 **"且"关系**，必须同时选考全部指定科目，缺一不可
- "或"类型是 **"或"关系**，任选一门即可
- 实际数据中"或"类型较少见，主要为理工科部分专业的 `物理或化学`

## 版本划分

资料包含两套选科要求：

### 2024 通用版（适用 2025-2026）

- 本科：1599 页 PDF，约 4.3 万条
- 专科：1191 页 PDF，约 3 万条
- 位置：`raw/2026/政策文件原件/2024通用版...pdf`
- **2026 届主要参考此版本**

### 2027 通用版（2027 及以后）

- 本科：644 页 PDF
- 专科：456 页 PDF
- 位置：`raw/2026/政策文件原件/2027通用版...pdf`
- 2027 届起使用，部分专业要求有调整（如物理+化学要求比例上升）

- `_meta.json` — 元数据

**字段**：

| 字段 | 说明 |
|---|---|
| edition | 2024 / 2027 |
| level | 本科 / 专科 |
| school_code | 院校代码（5 位，如 10001） |
| school_name | 院校名称 |
| major_code | 专业代码（如 0809） |
| major_name | 专业（类）名称 |
| subject_requirement_raw | 原始选科要求文本 |
| subject_requirement_type | none/one/two/three |
| subjects_list | 涉及科目（"\|"分隔，如"物理\|化学"） |
| province | 院校所在省份 |

| 类型 | 数量 | 占比 |

**注意**：实际数据中未发现"或"类型（any），所有多科要求均为"且"关系。

## 查询方式

### 按选科组合查询可报专业

详见 [[topic_选科查询]]，提供按 20 种选科组合查询可报专业的方法。

### 按学校/专业查询要求

```python
import json
data = json.load(open("processed/选科要求/2024版_本科_适用2025-2026.json", encoding='utf-8'))
# 查北京大学所有专业
pku = [r for r in data if r['school_code'] == '10001']
# 查计算机类专业
cs = [r for r in data if '计算机' in r['major_name']]
```

## 文件组织（Markdown 分册）

## 关键原则

1. 2026 届主要参考 2024 通用版，但 **最终以 2026 年山东正式招生计划中公布的选科要求为准**
2. 选科要求只做初筛，不能替代招生章程核查
3. 部分专业还有体检、单科成绩、外语语种等附加要求
4. **不允许凭印象判断**："物化可报计算机"是常见认知，但实际需查 PDF 确认是"物化均须"还是"物化任一"

## 选科组合（山东 3+3）

从政、史、地、物、化、生 6 科选 3 科，共 **20 种组合**。常见组合：

- 物化生（传统理科，覆盖率最高）
- 物化地、物化政
- 史政地（传统文科）
- 史政生、史地生
- 其他组合

不同组合可报专业覆盖率差异大，物化类覆盖率最高。详见 [[topic_选科查询]]。
