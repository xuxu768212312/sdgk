# 山东省教育招生考试院

山东省高考政策的官方发布机构，简称"省考试院"。所有政策、数据、计划的最终来源。

## 官方入口

| 用途 | URL |
|---|---|
| 官网首页 | https://www.sdzk.cn |
| 夏季高考普通招考 | https://www.sdzk.cn/NewsList.aspx?BCID=20&CID=1117 |
| 高考志愿填报专栏 | https://www.sdzk.cn/NewsList.aspx?BCID=1081&CID=1083 |
| 志愿填报入口页 | https://www.sdzk.cn/Business.aspx?BID=4 |
| 招生考试信息平台 | https://wsbm.sdzk.cn |

## 主要职能

- 组织夏季高考报名、考试、评卷
- 划定并公布各类别分数线
- 发布一分一段表
- 公布招生计划与缺额计划
- 组织各批次投档录取
- 发布投档情况表与录取结果

## 使用原则

资料包内官方原件用于 **政策学习和咨询准备**。实际填报时必须再次核查最新通知，尤其是：

- 志愿填报时间
- 分数线
- 一分一段表
- 招生计划
- 缺额计划
- 填报注意事项
