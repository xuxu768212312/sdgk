# 2021 年山东高考

2021 年是山东新高考（3+3）第三年招生，历史数据可作为 2026 届参考。

## 可用数据

| 类别 | 文件位置 |
|---|---|
| 一分一段表 | `raw/2021/一分一段表.xls` |
| 常规批第 1 次投档表 | `raw/2021/常规批第1次投档表.xls` |
| 各类别分数线 | `raw/2021/分数线/页面.html` |
| 常规批第 2 次投档表 | `raw/2021/常规批第2次投档表/` |
| 常规批第 3 次投档表 | `raw/2021/常规批第3次投档表/` |
| 常规批第 2 次志愿计划 | `raw/2021/常规批第2次志愿计划/` |
| 常规批第 3 次志愿计划 | `raw/2021/常规批第3次志愿计划/` |
| 提前批第 2 次志愿计划 | `raw/2021/提前批第2次志愿计划/` |
| 高职注册入学计划 | `raw/2021/高职注册入学计划/`（5 个附件） |

## 2021 特殊注意

- 部分页面标题写作"常规批"，附件中需区分 **普通类与体育类**
- 第 3 次投档表附件 1 为体育类，附件 2 为普通类（顺序与别年不同）
- 高职注册入学计划含 5 个附件：普通类、艺术类、体育类、春季高考、春季高考高职院校专项
