# 高级决策模型

## 概述

本页面引入**决策科学、行为经济学、博弈论、概率统计**等领域的顶尖思维工具，用于强化志愿填报的决策质量。这些模型是对 [[topic_System2填报思维框架]] 的深度加固，让决策从"经验判断"升级为"科学计算"。

注意：本页的方法论可以参考公开资料，但正式方案中的招生计划、位次、分数线、选科要求和投档结果只能来自 S/A/B 级数据。互联网资料必须遵守 [[topic_互联网数据使用原则]]。

风险模型必须同时报告：

- 独立模型滑档概率：仅作乐观参考。
- 保守滑档概率：不假设志愿独立，作为正式硬闸门。

当两者冲突时，以保守滑档概率和红军审查为准。

## 1. 贝叶斯推理（Bayesian Inference）

### 核心思想

用新证据不断更新对假设的置信度。志愿填报中，考生录取概率不是静态判断，而是随数据更新动态调整。

### 贝叶斯公式

```
P(录取 | 证据) = P(证据 | 录取) × P(录取) / P(证据)
```

**志愿填报应用**：
- P(录取)：先验概率（基于位次法的初步判断）
- P(证据 | 录取)：似然度（历年录取者位次与考生相近的比例）
- P(录取 | 证据)：后验概率（结合新证据后的录取概率）

### 应用场景

#### 场景 1：位次波动的贝叶斯更新

```
先验：考生位次 15000，目标专业近 3 年平均位次 16000
     → 初步判断录取概率 70%

新证据：
  - 2025 年该专业扩招 20% → P(扩招|录取) 高
  - 2025 年该专业位次下降至 16500 → 进一步支持录取

后验：录取概率上调至 85%
```

#### 场景 2：多证据融合

```
P(录取) 先验 = 70%

证据 1：选科符合 → P(E1|录取)=0.95, P(E1)=0.8
证据 2：体检合格 → P(E2|录取)=1.0, P(E2)=0.95
证据 3：单科达标 → P(E3|录取)=0.9, P(E3)=0.7

后验 P(录取 | E1∩E2∩E3) 
  = 0.95 × 1.0 × 0.9 × 0.7 / (0.8 × 0.95 × 0.7)
  ≈ 0.85
```

### 贝叶斯思维要点

1. **先验很重要**：没有数据时不要假设 50%，用历史位次作先验
2. **证据更新**：每一条新信息（扩招、政策变化）都应更新概率
3. **避免极端**：概率永远在 0-1 之间，不要绝对化

## 2. 蒙特卡洛模拟（Monte Carlo Simulation）

### 核心思想

通过大量随机抽样模拟复杂系统的运行，用统计分布代替单点估计。志愿填报中，用于量化整体风险和期望收益。

### 应用场景

#### 场景 1：整体滑档风险模拟

**传统方法**：
```
整体风险 = Π(1 - p_i)  // 假设独立
```

**蒙特卡洛方法**：
```
重复 10000 次：
  对每个志愿 i：
    生成随机数 r ~ Uniform(0,1)
    若 r < p_i：标记为"录取"
    否则：标记为"未录取"
  若所有志愿都"未录取"：本次模拟"滑档"
  否则：本次模拟"录取"

统计：
  滑档频率 = 滑档次数 / 10000
  期望录取志愿序号 = 平均录取位置
  期望专业满意度 = 平均满意度评分
```

#### 场景 2：位次波动模拟

```
假设考生位次服从 N(15000, 500²) 正态分布
对每次模拟：
  1. 从正态分布抽样考生位次
  2. 计算每个志愿的录取概率
  3. 模拟投档过程
  4. 记录结果

输出：
  - 滑档概率分布
  - 录取志愿序号分布
  - 录取专业满意度分布
```

### 蒙特卡洛优势

- **处理相关性**：志愿间不独立时（同校不同专业），能准确建模
- **输出分布**：不只给期望值，给完整概率分布
- **可视化**：可用直方图展示风险分布

## 3. 凯利公式（Kelly Criterion）

### 核心思想

在多次重复博弈中，最优下注比例使长期资本增长最快。志愿填报中，用于在"冲"和"稳"之间分配志愿数量。

### 凯利公式

```
f* = (bp - q) / b

其中：
  f* = 最优投入比例
  b  = 赔率（盈亏比）
  p  = 胜率
  q  = 1 - p（败率）
```

### 志愿填报应用

#### 场景：冲 vs 稳的志愿数量分配

**设定**：
- 冲的志愿：录取概率 30%，"收益"为好学校（收益系数 b=3）
- 稳的志愿：录取概率 70%，"收益"为匹配学校（收益系数 b=1）

**凯利计算**：
```
冲的凯利比例：
  f* = (3 × 0.3 - 0.7) / 3 = 0.2 / 3 ≈ 6.7%

稳的凯利比例：
  f* = (1 × 0.7 - 0.3) / 1 = 0.4 = 40%
```

**解释**：冲的志愿数量应占总数的 6.7%，稳的占 40%。

**实际调整**：
- 凯利公式给出理论最优，实际应考虑风险偏好
- 保守型考生可"半凯利"（冲 3%，稳 20%）
- 激进型考生可"1.5 倍凯利"（冲 10%，稳 60%）

#### 凯利公式的启示

1. **不要全冲**：即使胜率 30%，凯利比例也只有 6.7%
2. **主力放稳**：稳的志愿是长期增长的核心
3. **保底必须有**：凯利假设可重复博弈，志愿填报只有一次，需保底

## 4. MECE 原则（Mutually Exclusive, Collectively Exhaustive）

### 核心思想

分类时做到"相互独立、完全穷尽"。志愿填报中，用于确保 96 个志愿覆盖所有可能性，不重不漏。

### 应用场景

#### 场景 1：志愿分类的 MECE

```
按梯度分类（MECE）：
  ├─ 冲（位次 < 目标 0.9）    ← 互斥
  ├─ 稳（位次 0.9-1.1）       ← 互斥
  ├─ 保（位次 1.1-1.2）       ← 互斥
  └─ 垫（位次 > 1.2）         ← 互斥
                               ← 合起来穷尽所有位次区间
```

#### 场景 2：专业选择的 MECE

```
按学科大类（MECE）：
  ├─ 工学
  ├─ 理学
  ├─ 医学
  ├─ 农学
  ├─ 文学
  ├─ 历史学
  ├─ 哲学
  ├─ 经济学
  ├─ 法学
  ├─ 教育学
  ├─ 管理学
  ├─ 艺术学
  └─ 军事学
               ← 13 个大类互斥且穷尽
```

#### 场景 3：风险来源的 MECE

```
退档风险来源（MECE）：
  ├─ 体检受限
  ├─ 单科成绩
  ├─ 外语语种
  ├─ 外语口试
  ├─ 综合素质评价
  └─ 总分低额满
               ← 6 类互斥且穷尽官方退档原因
```

### MECE 检查清单

1. **互斥性**：各类别之间有无重叠？
2. **穷尽性**：有无遗漏的情况？
3. **层级性**：分类层级是否一致？
4. **一致性**：分类标准是否统一？

## 5. SWOT 分析

### 核心思想

从优势（Strengths）、劣势（Weaknesses）、机会（Opportunities）、威胁（Threats）四维度分析决策对象。

### 应用场景：考生 SWOT 分析

#### 示例：中分段考生 SWOT

```
优势（S）：
  - 物化生选科，专业覆盖广
  - 数学成绩突出（130+）
  - 位次稳定（3 年数据波动小）

劣势（W）：
  - 英语成绩一般（110）
  - 无竞赛奖项
  - 城市资源有限（山东县级）

机会（O）：
  - 2026 新增 38 个本科专业，竞争小
  - 山东大学扩招
  - 计算机行业需求仍旺

威胁（T）：
  - 计算机专业报考热度上升
  - 考研竞争加剧
  - AI 替代基础编程岗位
```

#### SWOT 矩阵策略

|         | 机会（O） | 威胁（T） |
|---------|----------|----------|
| **优势（S）** | SO 策略：用数学优势冲计算机新增专业 | ST 策略：数学优势 + AI 难替代的方向（算法、系统） |
| **劣势（W）** | WO 策略：避开英语要求高的专业 | WT 策略：避开红海专业，选差异化路径 |

## 6. 期望效用理论（Expected Utility Theory）

### 核心思想

决策不应只看期望收益，要考虑效用函数（风险偏好）。

### 公式

```
EU = Σ p_i × u(x_i)

其中：
  EU  = 期望效用
  p_i = 结果 i 的概率
  u(x_i) = 结果 i 的效用
```

### 应用场景

#### 场景：专业选择的效用函数

```
效用函数 u(专业) = w1 × 就业率 + w2 × 薪资 + w3 × 兴趣 + w4 × 考研率

考生 A（就业导向）：w1=0.5, w2=0.3, w3=0.1, w4=0.1
考生 B（兴趣导向）：w1=0.2, w2=0.2, w3=0.5, w4=0.1

对同一专业"计算机科学"：
  就业率 95%，薪资 12000，兴趣 7/10，考研率 30%

考生 A 的效用：
  0.5×0.95 + 0.3×12000/15000 + 0.1×0.7 + 0.1×0.3
  = 0.475 + 0.24 + 0.07 + 0.03 = 0.815

考生 B 的效用：
  0.2×0.95 + 0.2×0.8 + 0.5×0.7 + 0.1×0.3
  = 0.19 + 0.16 + 0.35 + 0.03 = 0.73
```

**结论**：同一专业对不同考生效用不同，志愿排序应个性化。

## 7. 行为经济学偏差清单

### 1. 损失厌恶（Loss Aversion）

- **表现**：对损失的痛苦感是对等收益快乐感的 2 倍
- **志愿填报**：不敢"冲"，全部填"稳"，导致错失更好学校
- **防范**：量化风险，接受适度风险以换取收益

### 2. 沉没成本谬误（Sunk Cost Fallacy）

- **表现**：因已投入而继续投入
- **志愿填报**：已研究某学校 10 小时，即使发现不合适也硬填
- **防范**：每次决策独立评估，不考虑已投入时间

### 3. 锚定效应（Anchoring Effect）

- **表现**：过度依赖第一个信息
- **志愿填报**：以某一年数据为锚，忽视其他年份数据
- **防范**：用 3 年平均，避免单年锚定

### 4. 确认偏差（Confirmation Bias）

- **表现**：只关注支持自己判断的信息
- **志愿填报**：认定某专业好，只看正面信息
- **防范**：主动寻找反面证据

### 5. 过度自信（Overconfidence）

- **表现**：高估自己判断的准确性
- **志愿填报**：认为"冲"的志愿一定能进
- **防范**：量化录取概率，承认不确定性

### 6. 从众心理（Herd Mentality）

- **表现**：盲目跟风热门专业
- **志愿填报**：因计算机热，全部填计算机
- **防范**：基于个人位次和兴趣决策

### 7. 现状偏差（Status Quo Bias）

- **表现**：偏好维持现状
- **志愿填报**：不愿跨省，只填省内学校
- **防范**：客观评估省外机会

### 8. 框架效应（Framing Effect）

- **表现**：同一信息不同表述影响决策
- **志愿填报**："录取率 30%" vs "淘汰率 70%"，前者更乐观
- **防范**：用统一框架（概率）表述

## 8. 博弈论视角

### 志愿填报的博弈结构

```
参与者：所有山东考生
策略：选择 96 个志愿的排序
收益：被理想专业录取

博弈类型：不完全信息静态博弈
  - 不完全信息：不知道他人志愿
  - 静态：同时填报
```

### 纳什均衡启示

- 热门专业（计算机、临床医学）竞争激烈，纳什均衡下位次要求高
- 冷门专业有"套利空间"：相同位次能进更好学校
- **策略**：在个人偏好内，寻找"价值洼地"（好学校的冷门专业）

### 零和博弈思维

- 山东高考是相对零和博弈（名额固定）
- 你的录取 = 他人的落榜
- 位次而非分数决定结果

## 9. 决策树综合应用

### 完整决策树

```
1. 考生定位
   ├─ 位次（核心）
   ├─ 分数段（顶尖/高分/中分/低分）
   └─ 选科组合

2. 专业方向（张雪峰八连问）
   ├─ 学医/学农/当老师
   ├─ 文理兼招
   ├─ 带化学/物理/数学
   └─ 传统工科/新型工科/边缘专业

3. 优先级决策（胡向阳四优先）
   ├─ 地域优先
   ├─ 职业优先
   ├─ 专业优先
   └─ 学校优先

4. 候选集筛选（MECE）
   ├─ 按梯度分类（冲稳保垫）
   ├─ 按地域分类
   └─ 按学校层次分类

5. 风险评估
   ├─ 贝叶斯概率更新
   ├─ 蒙特卡洛模拟
   ├─ 凯利公式分配
   └─ SWOT 分析

6. 效用优化
   ├─ 期望效用计算
   ├─ 个性化权重
   └─ 行为偏差检查

7. 验证与调整
   ├─ 防错清单核查
   ├─ 模拟投档
   └─ 多方案比较
```

## 10. 顶尖专家思维总结

### 核心能力

1. **数据驱动**：所有判断基于 `processed/` 数据，不凭感觉
2. **流程化**：System2 六步流程，不跳步
3. **风险量化**：用概率和分布，不用"可能""大概"
4. **个性化匹配**：效用函数因人而异
5. **偏差自省**：主动检查 8 类行为偏差

### 决策质量评估

| 维度 | 普通水平 | 顶尖水平 |
|------|---------|---------|
| 数据使用 | 单年分数 | 3 年位次 + 蒙特卡洛 |
| 风险判断 | "应该能进" | 概率 70% + 置信区间 |
| 梯度设计 | 凭经验 | 凯利公式 + MECE |
| 专业选择 | 跟风热门 | 八连问 + 效用函数 |
| 偏差检查 | 无 | 8 类行为偏差清单 |
| 验证方式 | 看录取结果 | 模拟投档 + 多方案 |
