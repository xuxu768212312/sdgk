# 填报防错清单

每个学生出最终方案前，按此清单逐项核查。原始清单：`raw/_common/防错规则/01-正式填报防错总清单.md`。

## 一、学生基础信息

- [ ] 姓名、身份证号、考生号与报名信息一致
- [ ] 高考总分、全省位次来自官方成绩查询或官方短信
- [ ] 选科组合核对无误
- [ ] 外语语种核对无误
- [ ] 体检结论已查看，限报项目已记录
- [ ] 户籍、学籍、报名地、生源地已确认
- [ ] 学生本人和家长对地域、专业、费用、风险偏好达成一致

## 二、考试院官方数据

- [ ] 使用当年山东省教育招生考试院发布的一分一段表
- [ ] 使用当年各类别分数线
- [ ] 使用当年《填报志愿指南》或官方志愿辅助系统中的招生计划
- [ ] 第 2/3 次志愿使用考试院公布的剩余/缺额计划
- [ ] 关注每次填报前考试院发布的"填报注意事项"
- [ ] 核查志愿填报时间，避免错过截止

## 三、本科/专科分开

- [ ] 本科计划和专科计划分开建池
- [ ] 本科历史投档数据和专科历史投档数据不混用
- [ ] 本科《填报志愿指南》和专科《填报志愿指南》分开核查
- [ ] 一段线、二段线、特殊类型招生控制线适用场景分清
- [ ] 普通类、艺术类、体育类、春季高考分清，不跨类别误填

详见 [[topic_本科专科分开]]。

## 四、每个志愿逐项核查

- [ ] 批次正确
- [ ] 层次正确：本科或专科
- [ ] 学校名称、院校代码正确
- [ ] 专业/专业类名称、专业代码正确
- [ ] 选科要求符合
- [ ] 招生计划数已核查
- [ ] 学费、住宿费、中外合作或高收费标识已核查
- [ ] 校区、办学地点已核查
- [ ] 体检限制已核查
- [ ] 单科成绩要求已核查
- [ ] 外语语种、外语口试要求已核查
- [ ] 招生章程已核查
- [ ] 大类招生包含专业和分流规则已核查
- [ ] 转专业政策已核查

## 五、特殊类型

- [ ] 提前批是否报考已确认
- [ ] 军校、公安、消防、定向军士等政审、体检、面试、体测要求已核查
- [ ] 公费师范生、公费医学生、公费农科生等协议、服务期、就业地已确认
- [ ] 地方专项、高校专项等资格已通过审核或公示
- [ ] 艺术类统考类别、文化线、综合分、校考/省际联考要求已核查
- [ ] 体育类专业测试成绩、综合分、合格线已核查

## 六、最终提交

- [ ] 志愿顺序已由学生本人确认
- [ ] 冲、稳、保、垫底结构合理
- [ ] 不可接受的专业、城市、费用类型已剔除
- [ ] 填报系统中最终顺序与方案表一致
- [ ] 学生本人保存最终志愿确认信息
- [ ] 登录密码、短信验证码未交由他人代管

## 关键原则

1. **先选科，后位次**：先按选科过滤可报专业
2. **本科专科分开**：数据池、风险判断、计划来源全部独立
3. **位次优先**：跨年比较只看位次，不看分数
4. **志愿次数对应**：第 2/3 次必须用当次剩余计划
5. **以官方为准**：山东省教育招生考试院发布为最终依据
