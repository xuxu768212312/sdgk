# 张雪峰八连问方法论

## 概述

张雪峰的"八连问"是一套**面向普通家庭、就业导向**的专业选择决策树。通过 8 个递进式是非问题，帮考生在数本科目中快速定位专业方向。核心逻辑：**工具理性压倒价值理性**——只关注就业、考公、考研的效率和成本，不关心学生"喜欢还是不喜欢"。

## 八连问决策树

```
Q1: 学医吗？
  ├─ 是 → 医学类专业（临床、口腔、麻醉、影像等）
  └─ 否 ↓

Q2: 学农吗？
  ├─ 是 → 农学类专业（动物医学、园林、种子科学等）
  └─ 否 ↓

Q3: 当老师吗？
  ├─ 是 → 师范类专业（语数英物化生政史地 + 学前教育）
  └─ 否 ↓

Q4: 接受文理兼招吗？
  ├─ 是 → 经济、金融、会计、法学、工商管理类
  └─ 否 ↓

Q5: 带化学吗？
  ├─ 是 → 化学、化工、制药、材料、环境、生物相关
  └─ 否 ↓

Q6: 带物理吗？
  ├─ 是 → Q7: 带物理的 3 个大方向
  │        ├─ 重力学的传统工科（机械、土木、水利、航空航天）
  │        ├─ 重电学的新型工科（电子、通信、电气、自动化、计算机）
  │        └─ 其他边缘专业（力学、热能、核工程）
  └─ 否 ↓

Q7: 带物理有3个大方向
  └─ 见 Q6 分支

Q8: 带数学吗？
  ├─ 是 → 数学、统计、计算机（以数学为主的专业）
  └─ 否 → 文学、语言、新闻、历史、哲学、艺术
```

## 核心理念

### 1. 就业导向三原则

- **毕业后必须能找到工作赚到钱**
- **专业至少要为考公/考研提供竞争优势**
- **不问喜不喜欢，只问能不能就业**

### 2. 工具理性逻辑

- 只关注目标的效率和成本
- 不关心学生是否"喜欢还是不喜欢"该专业
- 适合普通家庭、资源有限、需要快速变现的考生

### 3. 避坑原则

- 普通家庭避开"天坑专业"（生化环材，除非明确要读博）
- 避开"假大空"专业（管理类、营销类，除非家里有企业）
- 避开"万金油"专业（什么都学，什么都不精）

## 适用人群

### 强烈推荐

- 普通家庭、农村家庭
- 父母无相关行业资源
- 分数中等、需要靠专业就业
- 对未来职业方向无明确想法

### 谨慎使用

- 家里有企业/行业资源（应优先利用资源）
- 有强烈专业兴趣（兴趣优先，但需评估就业可行性）
- 分数顶尖（可优先学校，专业弱化）
- 计划出国深造（优先学校品牌）

## 八连问的局限

### 1. 忽视个人兴趣

- 完全不问"喜欢什么"，可能导致大学四年痛苦
- 兴趣与就业的平衡需自行把握

### 2. 静态就业观

- 基于当前就业市场判断，4 年后可能变化
- AI、新能源等新兴领域难以覆盖

### 3. 普通家庭预设

- 对有资源的家庭不适用
- 中产以上家庭可兼顾兴趣和资源

### 4. 专业壁垒假设

- 假设专业决定职业，实际跨专业就业普遍
- 计算机、金融等专业跨专业流入多

## 扩展：专业选择 4 步法

张雪峰还提出专业选择 4 步法，与八连问配套使用：

1. **城市决定视野**：优先一线城市和新一线
2. **学校决定圈层**：985/211/双一流的校友资源
3. **专业决定职业**：技术类专业壁垒高
4. **兴趣决定坚持**：在就业前提下兼顾兴趣

## 综合应用示例

### 案例：普通家庭理科生物化生

**考生背景**：
- 分数 560，位次 15000
- 父母务农，无行业资源
- 无明确兴趣

**八连问应用**：
1. 学医吗？→ 否（分数不够临床医学）
2. 学农吗？→ 否（不想当农技员）
3. 当老师吗？→ 可考虑（物理/化学老师）
4. 接受文理兼招吗？→ 否（想学理工科）
5. 带化学吗？→ 可考虑（应用化学、化工）
6. 带物理吗？→ 是
7. 带物理哪个方向？→ 重电学新型工科（电气、自动化、计算机）
8. 带数学吗？→ 是（计算机、统计）

**结论**：优先计算机、电气、自动化，次选统计、数学，保底化工、应用化学。
