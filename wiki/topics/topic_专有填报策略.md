# 专有填报策略

## 概述

本页面汇总山东新高考志愿填报的专有策略体系，涵盖数据驱动的核心方法、梯度设计原则、分档决策模型和风险评估技术。所有策略均基于 [[topic_System2填报思维框架]] 的六步决策流程。

正式方案还必须通过两个机器闸门：

- 选科硬闸门：`scripts/audit_volunteer_subjects.py`
- 策略优化闸门：`algorithms/strategy_optimizer.py`

## 1. 位次法（核心策略）

### 原理

山东实行等级赋分制，跨年比较不能用分数，只能用位次。位次法是最科学、最可靠的填报方法。

### 操作步骤

1. **确定考生位次**
   - 查 `processed/一分一段表/<year>.json`
   - 找到考生分数对应的累计人数（total_cumulative）
   - 该累计人数即为考生位次

2. **查询目标位次**
   - 查 `processed/投档表/<year>_round1.json`
   - 找到目标专业/学校近 3 年的最低投档位次（min_rank）
   - 计算 3 年平均位次

3. **比较判断**
   ```
   考生位次 < 目标位次（数值更小）→ 有希望
   考生位次 ≈ 目标位次 → 稳妥
   考生位次 > 目标位次 → 风险大
   ```

### 录取概率公式

```
比值 = 考生位次 / 目标位次

录取概率 ≈ f(比值)
  - 比值 < 0.9 → 冲刺（概率 20-40%）
  - 比值 0.9-1.1 → 稳妥（概率 60-80%）
  - 比值 > 1.1 → 保底（概率 90%+）
```

### 示例

假设考生位次 15000，目标专业近 3 年平均投档位次 16000：
```
比值 = 15000 / 16000 = 0.9375
录取概率 ≈ 60-80%（稳妥）
```

### 优势与局限

**优势**：
- 跨年可比，不受赋分制影响
- 数据可得，精度高
- 逻辑清晰，易于理解

**局限**：
- 需要 3 年数据平滑波动
- 对新增专业/学校无效（无历史数据）
- 未考虑招生计划变化

## 2. 线差法（辅助策略）

### 原理

用考生分数与批次线的差值，对比目标学校历年录取平均分与批次线的差值。

### 公式

```
考生线差 = 考生分数 - 当年批次线
目标线差 = 目标学校历年平均分 - 对应年份批次线

判断：考生线差 ≥ 目标线差 → 有希望
```

### 适用场景

- 批次线波动较大的年份
- 快速粗筛，不依赖一分一段表
- 位次法失效时的备选方案

### 示例

假设考生分数 580，一段线 441，目标学校近 3 年平均录取分 575：
```
考生线差 = 580 - 441 = 139
目标线差 = 575 - 441 = 134（假设批次线稳定）

考生线差 > 目标线差 → 有希望
```

### 局限性

- 赋分制下分数跨年不可比
- 精度低于位次法
- 仅作辅助，不作为主要依据

## 3. 冲稳保垫梯度策略

### 比例设计（96 个志愿）

```
冲：20-25 个（位次比目标低 10% 左右，录取概率 20-40%）
稳：35-40 个（位次与目标持平，录取概率 60-80%）
保：25-30 个（位次比目标高 10-15%，录取概率 90%+）
垫：5-10 个（位次比目标高 20%+，几乎 100% 录取）
```

### 位次梯度

| 梯度 | 位次关系 | 录取概率 | 作用 |
|------|----------|----------|------|
| 冲 | 考生位次 = 目标位次 × 0.9 | 20-40% | 争取更好学校 |
| 稳 | 考生位次 ≈ 目标位次 | 60-80% | 主力志愿 |
| 保 | 考生位次 = 目标位次 × 1.1 ~ 1.15 | 90%+ | 确保录取 |
| 垫 | 考生位次 = 目标位次 × 1.2+ | ~100% | 防止滑档 |

### 关键原则

1. **冲的志愿只保学校不保专业**
   - 投档后可能被调剂到冷门专业
   - 适合对学校有强烈偏好、对专业不敏感的考生

2. **稳的志愿学校专业都匹配**
   - 录取概率高，专业满意度高
   - 是 96 个志愿的核心

3. **保的志愿确保录取**
   - 即使前序志愿全部失败，也能被录取
   - 选择自己可以接受的专业

4. **垫的志愿防止滑档**
   - 极端情况下的安全网
   - 选择绝对能接受的专业

### 梯度间距

- 相邻志愿位次差距：500-1000 位
- 梯度间位次差距：10-15%
- 确保梯度间有明显区分度

### 示例分配（96 个志愿）

```
冲（24 个）：位次 14000-15000
稳（38 个）：位次 15000-16500
保（26 个）：位次 16500-18000
垫（8 个）：位次 18000-20000
```

### 机器优化器

候选池形成后，运行：

```bash
python algorithms/strategy_optimizer.py \
  --input students/某考生/志愿方案/candidates.json \
  --risk-profile standard \
  --slots 96 \
  --out students/某考生/志愿方案/strategy_optimized.json
```

优化器会拦截：

- 选科未 `PASS`
- 缺少 `evidence_id`
- 缺少 `source_file`
- 数据质量非 S/A/B
- 缺少或异常的录取概率
- 缺少或异常的效用分
- 重复的“院校+专业”候选
- 垫底志愿不足或冲稳保垫配额失衡
- 保守滑档概率超限

输出 `hard_gate_passed=false` 时，必须回退调整候选池，不得交付。

优化器同时输出两个风险值：

| 指标 | 含义 | 用法 |
|---|---|---|
| `independent_model_slip_probability` | 假设志愿相互独立时的滑档估计 | 仅作乐观参考 |
| `conservative_slip_probability` | 不假设独立，用最强安全志愿失败概率估计 | 硬闸门依据 |

正式交付以 `conservative_slip_probability` 为硬闸门，不能只看独立模型的低滑档数。

## 4. 分档决策模型（不同分数段策略）

### 分档标准

| 分数段 | 位次区间（参考） | 对应层次 |
|--------|------------------|----------|
| 顶尖分段 | 前 1% | 清北复交 |
| 高分段 | 1-5% | 985/211 |
| 中分段 | 5-30% | 普通本科 |
| 低分段 | 30-70% | 三本/专科 |

### 各档策略

#### 顶尖分段（清北复交）

**优先级**：学校 > 专业 > 城市

**策略类型**：激进型

**关键考量**：
- 院校为主，专业弱化
- 985 院校地点不会太差，城市因素可放后
- 冲名校，专业可调剂

**志愿设计**：
- 冲：30 个（清北复交 + 华五）
- 稳：40 个（中坚 985）
- 保：20 个（末流 985/211）
- 垫：6 个（确保录取）

#### 高分段（985/211）

**优先级**：学校 + 专业 > 城市

**策略类型**：稳妥型

**关键考量**：
- 院校与专业结合
- 可在"冲名校"同时兼顾专业方向
- 城市次之（985 大学地点不会太差）

**志愿设计**：
- 冲：20 个（冲 985 名校）
- 稳：40 个（985/211 匹配专业）
- 保：30 个（211/双一流）
- 垫：6 个（确保录取）

#### 中分段（普通本科）

**优先级**：专业 > 城市 > 学校

**策略类型**：稳妥型

**关键考量**：
- 专业为重点，城市很重要
- 就业/考研导向
- 城市资源重要（武汉、西安、成都等高校密集城市有额外资源）

**志愿设计**：
- 冲：20 个（冲好城市的普通本科）
- 稳：40 个（匹配专业 + 好城市）
- 保：30 个（确保录取）
- 垫：6 个（防止滑档）

**城市选择建议**：
- 一线城市：北京、上海、广州、深圳（就业机会多）
- 新一线：杭州、南京、成都、武汉（高校密集，考研资源好）
- 省会城市：省内资源集中

#### 低分段（三本/专科）

**优先级**：专业 > 就业 > 城市

**策略类型**：保守型

**关键考量**：
- 专业第一，就业为首
- 技术导向
- 本科 vs 专科根据目标权衡

**决策树**：
```
目标是什么？
  ├─ 考公/考研 → 尽量留本科（即使学校差）
  └─ 技术就业 → 可选专科技术类专业
```

**志愿设计**：
- 冲：15 个（冲本科）
- 稳：40 个（本科/专科匹配专业）
- 保：35 个（确保录取）
- 垫：6 个（防止滑档）

**专业推荐**：
- 技术类：计算机、电气、机械、护理
- 就业类：学前教育、会计、电子商务
- 考公类：法学、汉语言、行政管理

## 5. 专业/学校/城市优先级决策

### 四种优先策略（胡向东教授）

1. **地域优先**
   - 适用：职业方向不明确时
   - 理由：城市决定文化底蕴、教学资源、就业机会
   - 示例：想去北京 → 优先北京高校

2. **职业优先**
   - 适用：职业选择已"有谱"、分数较高有选择余地
   - 理由：职业目标明确，专业选择围绕职业展开
   - 示例：想当医生 → 优先医学专业

3. **专业优先**
   - 适用：专业特长明显，或分数较低学校选择性不多
   - 理由：专业决定就业方向，学校可妥协
   - 示例：想学计算机 → 优先计算机专业强的学校

4. **学校优先**
   - 适用：无明确职业方向、成绩均衡；踩线考生；计划出国深造
   - 理由：学校品牌和校友资源重要
   - 示例：想进 985 → 优先 985 学校，专业可调剂

### 决策树

```
有明确专业兴趣？
  ├─ 是 → 专业优先（用目标专业平均分筛选学校）
  └─ 否 → 分数段判断
           ├─ 高分 → 学校优先（冲名校，进校后分流）
           └─ 中低分 → 城市优先（就业/考研资源）
```

### 优先级权衡矩阵

| 优先级 | 适用分数段 | 适用人群 | 风险 |
|--------|------------|----------|------|
| 学校优先 | 高分段 | 无明确方向、踩线考生 | 可能被调剂到冷门专业 |
| 专业优先 | 中低分段 | 有明确兴趣、就业导向 | 学校可能差一些 |
| 城市优先 | 中分段 | 就业/考研导向 | 专业和学校可能妥协 |

## 6. 风险评估与量化

### 风险类型

#### 退档风险

**定义**：投档后被高校退回

**原因**：
- 体检受限（色盲、视力、身高等）
- 单科成绩不达标（英语、数学等）
- 外语语种限制（只招英语考生）
- 不服从调剂（山东"专业+学校"模式下也会退档）

**防范**：
- 仔细阅读招生章程
- 核对体检结论
- 确认单科成绩要求
- 服从调剂（虽然山东模式下仍可能退档）

#### 滑档风险

**定义**：96 个志愿全部未投档

**原因**：
- 梯度设计不合理，全部填"冲"
- 位次判断失误
- 招生计划大幅减少

**防范**：
- 必须有 5-10 个"垫"底志愿
- 合理分配冲稳保比例
- 用 3 年平均位次，不用单年数据

### 风险量化公式

#### 单志愿风险

```
单志愿风险 = 1 - 录取概率
```

#### 整体风险

```
整体风险 = Π(1 - 录取概率_i)  // i = 1 to 96
```

**解释**：
- 假设每个志愿独立
- 整体风险 = 所有志愿都未投档的概率
- 目标：整体风险 < 5%

#### 示例计算

假设 96 个志愿的录取概率分别为：
- 冲（24 个）：平均 30%
- 稳（38 个）：平均 70%
- 保（26 个）：平均 95%
- 垫（8 个）：平均 99%

```
整体风险 = (1-0.3)^24 × (1-0.7)^38 × (1-0.95)^26 × (1-0.99)^8
        = 0.7^24 × 0.3^38 × 0.05^26 × 0.01^8
        ≈ 0.0002 × 0.000000000000000000000000000000000000000 × ...
        ≈ 0（几乎为 0）
```

**结论**：整体风险极低，方案安全。

### 风险等级

| 风险等级 | 整体滑档概率 | 建议 |
|----------|--------------|------|
| 低风险 | < 5% | 方案安全，可执行 |
| 中风险 | 5-15% | 需增加保底志愿 |
| 高风险 | > 15% | 需重新设计梯度 |

### 风险调整策略

**如果风险过高**：
1. 增加"保"和"垫"的志愿数量
2. 降低"冲"的志愿数量
3. 选择录取概率更高的学校/专业

**如果风险过低**：
1. 可适当增加"冲"的志愿数量
2. 提高"稳"的志愿质量
3. 在风险可控前提下，最大化个人偏好

## 7. 综合应用示例

### 案例：考生位次 15000，中分段

#### Step 1: 定位
- 考生位次：15000
- 对应分数：约 560 分（参考 2025 年一分一段表）
- 分数段：中分段（普通本科）

#### Step 2: 筛选
- 选科：物化生
- 批次：普通类常规批
- 类别：普通类
- 候选集：约 300 个专业+学校

#### Step 3: 排序
- 冲（24 个）：位次 13500-14500（比值 0.9-0.97）
- 稳（38 个）：位次 14500-16000（比值 0.97-1.07）
- 保（26 个）：位次 16000-17500（比值 1.07-1.17）
- 垫（8 个）：位次 17500-19000（比值 1.17-1.27）

#### Step 4: 风险评估
- 整体风险：< 1%
- 风险等级：低风险

#### Step 5: 优化
- 优先级：专业 > 城市 > 学校
- 在"稳"梯度内，优先排列计算机、电气等就业好的专业
- 在"保"梯度内，优先排列济南、青岛等省内城市

#### Step 6: 验证
- 检查选科要求：全部符合
- 检查体检限制：无受限
- 检查梯度合理性：冲稳保垫比例 24:38:26:8 ≈ 2:4:3:1 ✓
- 检查风险等级：低风险 ✓

**最终方案**：96 个志愿，低风险，专业匹配度高。
