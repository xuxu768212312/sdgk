### 处理脚本（scripts/）

| 脚本 | 输入 | 输出 |
|---|---|---|
| `_process_score_table.py` | `raw/<year>/一分一段表.xls` | `processed/一分一段表/<year>.csv\|json` |
| `_process_admission.py` | `raw/<year>/常规批第N次投档表/` | `processed/投档表/<year>_round<n>.csv\|json` |
| `_process_scorelines.py` | `raw/<year>/分数线/*.pdf` | `processed/分数线/<year>.json` |
| `_process_plans.py` | `raw/<year>/*志愿计划/` | `processed/志愿计划/<year>.csv\|json` |
| `internet_source_policy.py` | URL/URL 列表 | 互联网来源质量上限与准入报告 |
| `check_subject_eligibility.py` | 单条院校专业 + 选科 | PASS/BLOCK/REVIEW 证据 |
| `audit_volunteer_subjects.py` | 96 志愿表 | 选科硬闸门审核报告 |
| `build_subject_index.py` | 选科 JSON | `subject_index.sqlite` |

### 策略算法（algorithms/）

| 脚本 | 输入 | 输出 |
|---|---|---|
| `strategy_optimizer.py` | 候选志愿 CSV/JSON | 组合排序、blocked 清单、梯度统计、滑档基线 |

脚本可重复运行，输出幂等。详见 `scripts/README.md`
